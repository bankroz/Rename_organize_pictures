# Third-Party Components

Python, PySide6/Qt/Shiboken, Pillow, FFmpeg/ffprobe and PyInstaller retain their
respective licenses. Distribution-supplied license texts are collected in the
portable package's licenses directory.

- Python: https://www.python.org/
- Qt for Python: https://doc.qt.io/qtforpython-6/
- Pillow: https://python-pillow.github.io/
- FFmpeg sources: https://ffmpeg.org/releases/
- Windows FFmpeg binary provider: https://www.gyan.dev/ffmpeg/builds/
- PyInstaller: https://pyinstaller.org/

The FFmpeg upstream README and license are included. Build configuration and
license details are available from `_internal/ffprobe.exe -L` and `-buildconf`.
Qt modules may have different license conditions. This is a preview, not a claim
that commercial delivery/license review or signing has been completed.
This repository has no project-level open-source license; these notices do not
grant a license to the application's own code.
